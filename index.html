📌 What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create web pages and web applications.

Key Points:

  • Standard markup language for Web pages
  • Describes the structure of a Web page using markup
  • Elements tell the browser how to display the content

How HTML Works

HTML code consists of tags that tell the web browser how to display text, images, and other multimedia elements.

📄 Basic HTML Structure

Every HTML document must start with a document type declaration.

Core Elements Breakdown:

  • <!DOCTYPE html> - Defines document type
  • <html> - Root element of an HTML page
  • <head> - Contains meta information about the page
  • <body> - Defines the document's body

📝 Essential HTML Tags

Tag Purpose & Examples:

  • <h1> - <h6> : Headings (largest to smallest)
  • <p> : Paragraph
  • <a> : Anchor (Hyperlink)
  • <img> : Image
  • <div> : Division / Container
  • <span> : Inline Container

📑 HTML Forms

Forms are used to collect user input.

Contact Us Form Fields:

  • Name
  • Email
  • Topic (General Inquiry, Support)
  • Message
  • Submit Form

🏷️ HTML Attributes

Attributes provide additional information about elements.

Important Attributes:

  • href - Specifies URL for links
  • src - Specifies image source path
  • alt - Alternate text for images
  • class - Styling class name
  • id - Unique element identifier
  • style - Inline CSS styles

📊 Tables in HTML

HTML tables are used to arrange data into rows and columns.
